# 공피하기 게임 (Ball Dodging Game)

Java 21 Swing 기반의 2D 아케이드 공피하기 게임입니다.

## 기능 특징
- **키보드 조작**: 방향키(↑, ↓, ←, →) 및 WASD 지원 (8방향 대각선 이동)
- **난이도 3단계**: 초급 / 중급 / 고급 — 공 속도, 생성 간격, 조준 정확도, 점수 배율이 달라짐
- **아이템**
  - ⭐ **별**: 보너스 점수 (+300 × 콤보 배율 × 난이도 배율)
  - 💣 **폭탄**: 화면에 있는 공을 전부 파괴 (파괴한 공 개수만큼 추가 점수)
- **콤보 & FEVER**: 7초 안에 아이템을 연속으로 먹으면 콤보가 쌓이고, 3콤보 달성 시 8초간 **FEVER** (모든 점수 ×2, 아이템 생성 2배).
  피버 중 아이템을 먹으면 피버 시간 +2초
- **다양한 공 타입**: 일반 공, 고속 공, 대형 공
- **점수 시스템**: 생존 점수 + 아이템 점수, 난이도별 최고 점수 기록
- **GUI**: 난이도 선택 카드 메뉴, 콤보/피버 게이지 HUD, 결과 화면 통계, 마우스 클릭 지원

## 조작
| 키 | 동작 |
|---|---|
| ← → / 1 2 3 | (메뉴) 난이도 선택 |
| Enter / Space | 게임 시작 |
| 방향키 / WASD | 이동 |
| P / ESC | 일시정지 · 재개 |
| R | (게임오버) 다시 하기 |
| M | (일시정지·게임오버) 메뉴로 |

## 밸런스 조정
- 난이도 수치: `model/Difficulty.java`
- 점수·콤보·피버 규칙: `model/ScoreSystem.java`

## 실행 요구사항
- Java 21 이상 (JDK 21)

## 실행 방법
- `run.bat` 실행 또는 직접 컴파일 후 실행
```bash
javac -d bin -encoding UTF-8 src/com/dodging/game/*.java src/com/dodging/game/*/*.java
java -cp bin com.dodging.game.Main
```
